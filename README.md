## 🧑‍💻 About me

Software engineer with an **MSc in Computer Science** from [University of Salerno (@Unisa)](https://www.unisa.it). I care about the whole stack, from data to deployment, but these are the things that keep me up at night:

- 🤖 **AI Engineering & Agentic Systems**: LLM apps, AI agents, tool calling, MCP, RAG pipelines and evals
- 🧠 **Machine Learning**: from classic ML to fine-tuning and shipping models to production (MLOps)
- 🗣️ **Natural Language Processing**: the field that turned into the LLM era
- 🛠️ **Software Engineering**: clean architecture, CI/CD, DevEx and AI-assisted development workflows
- 🚀 **Quantum Computing**: still science fiction, but I'm keeping an eye on it
